# AI Hand Gesture Control System

## Project Overview

The AI Hand Gesture Control System is a web-based application that uses Artificial Intelligence and Computer Vision to detect and recognize hand gestures in real time. It uses a webcam to capture hand movements and identifies different gestures using MediaPipe.

The application recognizes four basic hand gestures and displays their corresponding actions on the webpage.

## Objectives

- To detect human hands using a webcam.
- To recognize different hand gestures in real time.
- To connect recognized gestures with specific actions.
- To develop a simple and user-friendly web application.

## Features

- Real-time hand detection using a webcam.
- Recognition of four different hand gestures.
- Display of detected gestures on the webpage.
- Gesture-to-action mapping.
- Simple and user-friendly interface.
- Online access through GitHub Pages.

## Hand Gestures and Actions

| Hand Gesture | Assigned Action |
|---|---|
| Open Palm ✋ | Resume |
| Closed Fist ✊ | Pause |
| Victory ✌️ | Mouse Click |
| Thumb Up 👍 | Volume Up |

## How It Works

1. The user opens the web application.
2. The application requests webcam permission.
3. The webcam captures the user's hand.
4. MediaPipe detects the hand and identifies its landmarks.
5. JavaScript processes the hand landmarks to recognize the gesture.
6. The corresponding action is displayed on the webpage.
